# Paths removed from the bundled KOReader runtime, relative to runtime/.
# Blank lines and # comments ignored. Globs are expanded by the shell.

# ORDER MATTERS FOR DEBUGGING: the entries are grouped from "certainly unused"
# to "verify on device". If the app stops booting after a runtime bump, comment
# out the last group first and work upwards.

# The app only ever requires: ui/widget/*, ui/uimanager, ui/gesturerange,
# ui/geometry, ui/font, ffi/blitbuffer, ui/network/manager, luasettings,
# datastorage, plus luasocket/luasec/ltn12.

# --- document engines -------------------------------------------------------
# Only the three that nothing outside a document view can reach. Be very
# conservative here: the whole libs/ directory is ~10MB, while fonts and data
# below are where the real savings are, and a missing .so is a hard crash at
# startup. Notably KEPT:
#   libzstd      - libarchive links it, and device/generic/device.lua loads
#                  ffi/archiver at require time. Removing it broke boot.
#   libwrap-mupdf - ui/renderimage lazily falls back to it from ImageWidget.
#   libkoreader-nnsvg, liblodepng - image decoding paths under ImageWidget.
libs/libk2pdfopt*
libs/libkoreader-djvu*
libs/libkoreader-cre*
